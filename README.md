# Приглашение на свадьбу — Mirjamol & Sipora

Одностраничный сайт-приглашение. 23 сентября 2026, Самарканд, ресторан «AMIR».

## Как опубликовать

1. Загрузите содержимое этой папки в репозиторий (файлы должны лежать в корне, не внутри вложенной папки).
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты сайт будет доступен по адресу `https://ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`.

## Что где лежит

| Файл | Что это |
|---|---|
| `index.html` | вся страница: вёрстка, стили и скрипты |
| `img/` | иллюстрации и фото ресторана |
| `og.jpg` | превью для WhatsApp и Telegram |
| `.nojekyll` | отключает лишнюю обработку файлов на GitHub Pages |

## Что можно менять

Всё правится прямо в `index.html`, инструкция — в комментарии в самом начале файла.

- **Адрес сайта** — строки с `ЛОГИН.github.io` в шапке. Без правки превью в мессенджерах покажется без картинки.
- **Куда приходят ответы** — объект `CONTACT` в конце файла: номер WhatsApp и ник в Telegram.
- **Место и время** — секция `id="band-venue"`.
- **Дата** — `weddingDate` в скрипте таймера и выделенное число в календаре.
